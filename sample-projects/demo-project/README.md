# Demo Project

A sample project folder for testing the Command Center project setup.

## Goal
Test that a general agent from the Command Center library reads this project's `AGENTS.md` before doing any work, and applies its rules.

## Domains
- Frontend (landing page copy and layout)
- Content (short product descriptions)
- Review (independent check of finished work)

## Milestones (sample)
- M1: Landing page draft (due 2026-10-20)
- M2: Product descriptions, 5 items (due 2026-10-27)
- M3: Review and approval (due 2026-11-03)
