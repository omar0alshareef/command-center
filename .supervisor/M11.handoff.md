**Exit criteria, live** (built Electron app, temp project, requests from a separate Node process):
- with token, `task-update` → `in_progress`: 200, task returned in `in_progress`
- invalid status `bogus`: 400 `INVALID_INPUT`
- no token: 401
- `netstat`: only `127.0.0.1:38120 LISTENING` (nothing on 0.0.0.0)
- non-local peer / foreign Host: 403, covered by unit tests (cannot make a non-loopback connection from this machine).

**Deviations:** no Express (4 routes, node:http); Settings modal is M12 so the token UI sits in Agent Hub → Connect; `completed_at` accepted but ignored; status GET also needs the token. Mapping rules: see PROGRESS "M11 task-update".
