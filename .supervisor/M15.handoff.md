## Deviations, decisions, ambiguities (all also in PROGRESS.md)

- Library path: fixed `%APPDATA%\Command Center\library.db` (not Electron `userData`) so app, CLI and MCP agree; reported here as the roadmap asked. The operator's real library was never opened by the tests.
- A library agent is a **mirror row** in the project's `agents` table plus a `project_agents` link, kept current on open, on every dispatch pass and after a library edit. Provider/model of a library agent are edited only in the library (project override refused; read-only line in the Agent Hub).
- New 7th tab "Agents" placed last so Ctrl+1..6 did not move; hotkeys are 1..7. The smoke check and the old M13 live check that asserted 6 tabs now assert 7.
- Switching while runs are in flight forces cancelling them (with a confirm), because a run cannot outlive its project's database connection.
- Agents proposed by an approved plan are still created as project agents, not library agents (the roadmap lists writing AGENTS.md from a plan as out of scope; library creation from a plan was not specified).
- `propose_lesson` keeps an agent's suggested check as plain text inside the draft's prevention field; it can never be an active check.
- Bugs found by the live runs and fixed: title showed the database's project name; stale mirror after a library edit made while another project was open; project.json / AGENTS.md edits not reaching the notices (now 4 s poll + focus); per-row `db:changed` listener (MaxListenersExceededWarning) in the routing line; dark/light text-contrast failures in the Agent Hub (existing tiles and task-id links plus my first lessons markup), fixed with `.text-ink-accent` / `.text-ink-warning` and `--tag-ink` (no new colour).
