## What I built
**Main process** (`apps/desktop/src/main/`):
- `project.ts` `ProjectService`: owns the writer DB connection + watcher for the open project; `open/retry/info/getAll/close`.
- `watcher.ts`: `PRAGMA data_version` poll every 500 ms on a separate read-only connection is the authority; `fs.watch` on `.db`/`-wal` is only a hint; 100 ms debounce; on error emits `disconnected` and reconnects with exponential backoff (max 10 s), refetching after reconnect (D3).
- `ipc-handlers.ts`, `shared/ipc.ts`: typed contract, no SQL. Channels: `db:getAll`, `project:get|choose|retry`, events `db:changed`, `db:status`.
- `settings.ts` (saved root in `userData/config.json`), `config.ts` (`env > saved > null`), `index.ts` (wiring, `before-quit` closes DB).
- `preload/index.ts`: `contextBridge` exposes only the typed `Api`.
- `electron.vite.config.ts`: bundles `@command-center/core` (TS source) into main; `better-sqlite3` stays external.

**Core** (`packages/core`): added `openDbReadonly()`; made the seed deterministic (see "Deviations").

**Renderer** (`apps/desktop/src/renderer/`):
- `store.ts` (Zustand): `project, tracker, loading, error, sync{state,lastSyncAt}, activeTab, selectedMilestoneId, theme`; `init/refresh/chooseProject/retryProject`; refetches coalesce; `activeTab` + `theme` persisted.
- Shell: `TitleBar` (name, schedule pill, progress bar, sync indicator, theme toggle), `TabBar` (Lucide icons, sliding underline via `layoutId`, Review/Blocked/Active badges, `role=tablist`), `StatusBar` (clickable segments), `useHotkeys` (Ctrl/Cmd+1…5, Ctrl/Cmd+Tab).
- Shared UI (`components/ui/`): Tag, StatusDot, StatusTag, PriorityPill, DomainTag, ProgressRing, AgentAvatar, AssigneeChip, EmptyState, Skeleton, Toast host, Modal (native `<dialog>`), ConfirmDialog (focus on Cancel), SlidePanel, Tooltip (500 ms), Button.
- Screens: skeleton while loading, `Welcome` (folder picker), `FatalError` (path + error + Retry / Choose another project), inline error banner with Retry.
- Views (`views/index.tsx`): 5 placeholders showing real counts; empty state with "Copy hydration prompt" when there are no milestones.
- Tokens: dark + light CSS variables mapped into Tailwind `@theme`; focus ring, reduced-motion, pulse/shimmer keyframes.
- Tests: `apps/desktop/test/derive.test.ts` (new), `window-options.test.ts` (+ env/saved precedence).

- **Live sync (≤ 1 s, no refresh):** a second `better-sqlite3` connection in another process runs `UPDATE subtasks SET status='review' WHERE id=(SELECT id FROM subtasks WHERE status='todo' ORDER BY id LIMIT 1)`; the script polls the DOM until the Review badge increments. 6 samples: 109, 243, 474, 139, 610, 513 ms. Design bound is ~500 ms poll + 100 ms debounce + fetch/render, so the worst case is under 1 s but not by a wide margin.
- **Welcome** (`PROJECT_ROOT` unset, fresh profile): "Choose your project folder … Choose folder…".
- **Fatal** (`PROJECT_ROOT` = path of an existing file): "Can’t open the project database", the path, `EEXIST: file already exists, mkdir '…\package.json'`, buttons Retry / Choose another project.
- **Themes:** I viewed screenshots of dark Task Board and light Agent Hub; both looked right. My first screenshots caught the 200 ms underline animation mid-flight; after a 700 ms settle the underline sits under the active tab.
- **No raw SQL from the renderer:** `grep -rnE "db:query|db:run" apps packages` (source only, excluding node_modules/out) → 0 matches. The only channels are the six listed above.

## Deviations / ambiguities (also in PROGRESS.md)
- better-sqlite3 13 is N-API, so the Node build also loads in Electron 44 (verified with `ELECTRON_RUN_AS_NODE` and the full app). The "separate Electron-ABI copy" risk I raised in M1 is withdrawn; `electron-rebuild` is still needed for `node-pty` (M8).
- Store `sync` is `{state: live|syncing|disconnected, lastSyncAt}` rather than the blueprint's `synced` boolean (UI/UX §3.2 needs three states).
- `better-sqlite3` and `@command-center/core` added to `apps/desktop` dependencies (needed for the externalize/bundle behaviour).
- shadcn/ui still not initialised; components are hand-written on the tokens.
- Env `PROJECT_ROOT` is never persisted; only a folder picked in the dialog is saved. A nonexistent `PROJECT_ROOT` is created.
- Deferred, not in the exit criteria: command palette, `?` cheat-sheet, OS notifications, first-run checklist card (M12); webhook/terminal status-bar segments (M8/M11); per-element live-update flash (needs real elements, M3+).
- Fixed a flaky M1 test I had written: seeded milestones used wall-clock `CURRENT_TIMESTAMP`, so two seeds straddling a second boundary differed. The seed now sets `created_at/updated_at` explicitly. The full suite then passed 6 of 6 repeated runs.
- ESLint also ignores `.supervisor/**` (verification script, not product code).
