# M13.2 handoff: Calm theme (patch)

**Built**
- **Tokens:** a `:root[data-theme='calm']` block with every UI/UX §4.8 value. The study's hex values are exact: Ivory `#FAF9F4`, Forest `#0F5132`, Mint `#B7D9C1`, Stone `#D6D3C8`. The rest are the spec's inferred values.
  - Shared tokens with neutral defaults in the other themes: `--accent-soft`, `--focus`, `--scrim`, `--display`, `--radius-pill/card/inner`, `--shadow-card`, `--tag-ink`. They are mapped into the Tailwind `@theme` (`bg-accent-soft`, `font-display`).
- **Selecting it:** Settings → Theme gains "Calm" (Dark, Light, Calm, System). The title-bar button cycles dark → light → calm → system → dark and shows the next theme's icon. The default stays dark. The choice persists through the existing `cc-ui` store. `system` still follows the OS.
- **Components, CSS only (no per-view overrides):**
  - Buttons get a `btn` class and `data-variant`: pill shape, forest primary with an ivory label and a trailing arrow (`::after` with empty alt text), outlined secondary.
  - The Settings switch is 44×24; checkboxes are 18px with a 6px radius and a tick.
  - The selected tab is a forest segment.
  - The progress track uses `surface-3`.
  - The notification card gets a soft shadow.
  - Modals get a 20px radius, a soft shadow and a green-tinted scrim.
  - Inputs and selects are pill-shaped outside table cells.
  - Dense lists keep borders and no shadows.
- **Type:** Source Serif 4 (`@fontsource`, installed as an exact pin, offline) via `font-display`, used on the Settings, shortcut, milestone-panel, Agent Hub and Planning titles. It falls back to Inter in the other themes. Labels get wider tracking in Calm.
- **Shared-component contrast fixes, which also help light and dark:**
  - Agent-avatar initials and swim-lane phase labels use `--text`; the hue stays on the ring and tint.
  - `Tag` text mixes its hue toward `--text` by `--tag-ink` (100% in dark, so unchanged; 55% in light and Calm).
- **Terminal:** Calm uses the light ANSI palette.
