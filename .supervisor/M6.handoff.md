## What I built
**`apps/desktop/src/renderer/views/agent-hub/`**
- `AgentHub.tsx`: two columns (340 px fixed + fluid, each scrolls on its own). No connected agent: the "No agents connected" empty state with the real MCP snippet (unchanged text, so the M4 empty-state checks still apply).
- `AgentTree.tsx`: orchestrators on top, sub-agents indented under them with a connector line, chevron collapse (persisted), avatar, name, ACTIVE (green, pulsing) / IDLE / ERROR badge, live "2m ago", permission badges (3 then `+n`), mono action count, model line. Click filters the feed; right-click: View tasks (Task Board filtered to that assignee), Copy agent id.
- `SideCards.tsx`: Shared State (middle-truncated DB path + copy, sync dot, counts, "Last change"), Context Injection Preview (live, Copy → toast), Today's Summary (3 tiles + stacked contribution bar with legend).
- `ActivityFeed.tsx`: tabs `All | each agent | Manual | System`, search, sticky day headers, `@tanstack/react-virtual` list (fixed row heights), "↑ n new" pill with scroll anchoring, flash for new rows, "Load older" footer, "Waiting for the first agent action…" empty state. Agent text is rendered as text only.
- `Performance.tsx`: per-agent weekly cards (big total + tag bars).
**Plumbing:** `lib/agent-hub.ts` (pure helpers), `main/activity-api.ts` + IPC `activity.older` (read-only; renderer sends an anchor row id/timestamp, never SQL; zod-validated, limit ≤ 1000), store (`hubFilter`, `hubCollapsed` persisted, `olderLog`, `loadOlder`, `boardAssignee`), `useNow` hook, Task Board starts filtered when `boardAssignee` is set, `feed-flash` CSS (reduced-motion aware), new dependency `@tanstack/react-virtual`.
