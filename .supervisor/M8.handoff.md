## What I built
**Main process (`apps/desktop/src/main/`)**
- `shells.ts`: detects the shells that exist (Windows: PowerShell 7 if present, Windows PowerShell, Command Prompt, Git Bash, WSL; macOS/Linux: login shell, zsh, bash, fish, sh), default first (D8, D13).
- `pty.ts`: `PtyManager` (spawn / write / resize / kill / killAll, exit events). cwd is the project root, `PROJECT_ROOT` is in the environment. Output is coalesced per session (6 ms or 64 KB). Kill = `pty.kill()` plus `taskkill /T /F` on Windows so grandchildren die too.
- `terminal-api.ts` + IPC: the renderer chooses a **detected shell by id** (an unknown id falls back to the default, a path is never executed), session ids must match `term-N`, sizes are range-checked, writes are strings only.
- `index.ts`: `before-quit` kills all PTYs; a reload/navigation or a renderer crash also kills them.
**Renderer**
- `lib/terminal.ts`: xterm instances and their scrollback live outside React (store only mirrors the tab list); output that races the IPC reply is buffered; theme from the design tokens; custom key handling (Ctrl+Shift+C/V, Cmd+C/V, app shortcuts bubble).
- `views/terminal/TerminalPanel.tsx`: session tabs (name, running/exited dot, ×), `+` split button with detected-shell menu, Clear, font −/+ (persisted), collapsible quick-action chips (type, never run), exited banner with Restart, "No sessions" empty state, spawn-failure hint, fit on show/resize (ResizeObserver). Always mounted after the first visit, first visit auto-starts a session.
- Task modal: "Run prepare here" types `command-center prepare TASK-X` into the terminal (not executed).
- Deps: `node-pty` 1.1.0, `@xterm/xterm` 6, `addon-fit`, `addon-web-links`. README prerequisites rewritten.

## Visual review (screenshots viewed)
First session, full-screen test app, real `claude` TUI (and resized), exited banner, light theme. Bug found by looking: after switching to the light theme the terminal stayed dark. Cause: `App` sets `data-theme` in its own effect, which runs after the child's, so the child read stale tokens. The terminal now reads the tokens a frame later, and T2 asserts the colour change.

## Deviations / decisions (PROGRESS.md)
- **No `electron-rebuild`**: node-pty 1.1.0 ships `win32-x64`/`darwin` prebuilds that Electron 44 loads directly (proved by running the app). README no longer claims the VS Build Tools are required on Windows.
- Ctrl+W closes the session while the Terminal tab is open (per the spec), so the shell does not receive it there.
- No split panes (v1.1), no output backpressure (6 ms batching only; ceiling noted in `pty.ts`).
- Chips type `command-center …` even though that CLI arrives in M9.
