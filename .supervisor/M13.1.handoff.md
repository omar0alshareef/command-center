# M13.1 handoff: Stage-based roster (patch to M13)

**Built**
- **Migration 006:** `agents.executor` (`agent` | `external` | `human`, CHECK, default `agent`) and `agents.tool`. `operator` is `human`, `system` is `external`; every other existing agent reads back as `agent`.
- **Core `planning.ts`:**
  - `plan_capabilities` is renamed `plan_stages`; the field names (`capabilities`, `capability`) are kept.
  - Media stages `script`, `edit`, `voiceover`, `thumbnail`, `publish` are added.
  - `STAGE_EXECUTORS` is the one defaults table: edit = external "Video editor", voiceover = external "Voice tool", thumbnail = external "Image tool", publish = human, everything else = agent.
  - `TeamRole` gains `executor` and `tool`. `proposeTeam` picks human, then external, then agent from a role's stages.
  - `PlanTask` gains `brief` and `checklist`. On approve the brief becomes the task prompt and the checklist joins the acceptance criteria. No new table.
  - `validatePlan` rejects an external role without a tool.
  - The interview prompt asks decision questions only (deadlines, budget, on camera or own voice, content limits, target audience). The `plan_tasks` prompt asks for a brief and checklist on the external and human stages.
  - `approvePlan` passes executor and tool to `registerAgent`. `planCounts` gains `stages` by executor.
- **Agents:** `registerAgent` and the `Agent` schema carry executor and tool.
- **MCP:** `list_agents` returns `executor` and `tool`. No new write tools.
- **UI:**
  - Team tab: "Done by" select, "Tool" field, red when an external role has no tool.
  - Approve dialog: counts stages by executor.
  - Agent Hub: a chip per agent (`agent`, `external · tool`, `done by you`).
  - Planning: milestones show "Stages".
