# M13.3 handoff: Calm Dark (patch)

**Built**
- **Tokens:** `:root[data-theme='calm'][data-mode='dark']` with every UI/UX §4.8 Calm Dark value:
  - forest-black `#0C1410`, surfaces `#121C17`, `#18241E`, `#202F27`;
  - ivory text `#EEF0E6`, muted `#A3B5A9`;
  - Mint accent `#B7D9C1` with `--on-accent` `#0F3A25`, and accent-soft `rgba(183,217,193,.14)`;
  - success `#6FC48E`, warning `#E6B04F`, danger `#EE7B6F`, focus ring Mint;
  - `color-scheme: dark` and `--tag-ink` 100%.
- **Selecting it:** `calm-dark` is a fifth theme preference.
  - Settings lists Dark, Light, Calm, Calm Dark, System.
  - The title-bar cycle is dark → light → calm → calm-dark → system → dark.
  - `App` sets `data-theme="calm"` plus `data-mode="dark"`, and clears the mode on any other theme.
  - It persists through `cc-ui`, and `system` still maps to plain light or dark.
- **Components:** every M13.2 rule applies unchanged. Calm Dark only overrides:
  - ghost and secondary buttons are transparent;
  - the checkbox tick is dark;
  - Review cards get an amber border and tint, Blocked cards a red border;
  - Done cards get a muted title and a tick (`.done-mark`, hidden in every other theme, with a screen-reader "Done").
  - No shadows on dense surfaces.
- **`--on-accent` token:** white by default, ivory in Calm, dark green in Calm Dark. `text-white` on accent fills (primary button, the "NOW" flag, the activity filter chip, the "new entries" pill) became `text-on-accent`.
- **Domain palette (the M13.2 carry-over):** `DOMAIN_COLORS` is now `var(--domain-1..10)`.
  - Default themes keep the old colours.
  - Both Calm modes cycle amber, violet and blue, with no green.
  - Light Calm uses `#D97706`, `#7C5CD6`, `#2F6FB0` (inferred; added to the spec).
- **Terminal:** it uses the dark ANSI palette in Calm Dark.
